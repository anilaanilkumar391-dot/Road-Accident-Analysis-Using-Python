**Road Accident Analysis Using Python**

Project Overview

This project focuses on analyzing road accident data using Python. Exploratory Data Analysis (EDA) is performed to identify accident patterns, contributing factors, and useful insights.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset

The project uses the Road Accident Prediction India dataset.

Project Objectives

- Analyze road accident patterns.
- Identify factors contributing to accidents.
- Explore accident trends through data visualization.
- Understand accident severity and related patterns.

Files Included

- "Accident_Prediction.ipynb" – Python analysis notebook.
- "accident_prediction_india.csv" – Dataset.

Key Skills

Data Cleaning | Exploratory Data Analysis | Data Visualization | Python | Pandas

Conclusion

This project demonstrates the use of Python for exploring road accident data and identifying meaningful patterns and insights.
